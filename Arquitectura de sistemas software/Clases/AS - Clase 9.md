# Representacion de Arq con C4
> Propone una **forma progresiva de visualizar un sistema en 4 niveles**:
> 1. Contexto: *vision global del sistema y actores*
> 2. Contenedores: *como se divide el sistema en aplicaciones o servicios ejecutables*
> 3. Componentes: *modulos internos de cada contenedor*
> 4. Codigo: *clases, scripts o estructuras a bajo nivel (opcional)*
