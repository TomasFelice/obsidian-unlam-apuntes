# Agent as a Service (AaaS)

Denomina un modelo de entrega en el que se exponen agentes de IA como servicios mediante contratos de interacción. El alcance del término varía y no implica que todos los agentes tengan las mismas capacidades.

## Complemento de estudio

### Agentes como servicio

AaaS es una denominación de uso variable. Un agente expuesto por API puede interpretar objetivos, consultar herramientas y conservar contexto; eso no garantiza autonomía total ni lo convierte automáticamente en un patrón estandarizado.

Para diseñarlo, definir contrato de entrada y salida, herramientas permitidas, límites de ejecución y tratamiento de errores. Una acción con efectos externos necesita identificación de la solicitud y control de reintentos.

**TOGAF** es un marco de arquitectura empresarial: permite relacionar negocio, datos, aplicaciones y tecnología. No es una receta para elegir microservicios. El ADM organiza el desarrollo y la gestión de la arquitectura.

Fuente: [The Open Group: TOGAF](https://www.opengroup.org/togaf).
